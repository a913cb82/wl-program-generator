# Exercise Selection & Session/Week Structure — Roman "Training of the Weightlifter"

Source: research/roman-transcription/chunk-1..5.md. Page refs = transcription p-numbers.
Levels: low-class = Class III–II; classified = Class I + CMS (KMC); MS; MSIC. Periods: prep vs competition month.
No commentary — only source rules/numbers.

## 1. Classic vs assistance shares (monthly volume)

### Snatch block (p45)
- All snatch exercises = 20 ± 5% of general monthly volume.
- Within snatch block, classic snatch share:
  - Prep: low 50% / classified+CMS 45% / MS 40%.
  - Comp: low 50% / classified+CMS 43% / MS 38%.
  - Remainder = other snatch exercises.
- Good-snatch athletes or those perfecting technique do more special-assistance snatches, but large cut in classic snatches inhibits snatch improvement; keep equivalent totals per qualification across weight classes (p45–46).

### Clean-and-jerk block (p53)
- All jerk exercises (cleans + jerks) share of monthly volume:
  - Prep: low avg 28% / I+CMS 27% / MS 26%.
  - Comp: 28 / 28 / 27%.
- Of these, cleans = avg 17% (low) / 15% (I+CMS) / 13% (MS). Remainder = jerks.
- Classic clean share of all clean lifts: low 44% / I+CMS 40% / MS 38% (both periods implied).
- Classic jerk share of all jerks:
  - Prep: low 68% / I+CMS 58% / MS 46%.
  - Comp: low 68% / I+CMS 54% / MS 43%.
- More classic jerks the lighter the class (light-class "thrust" difficulty from Class I/CMS up); other jerks identical across classes, so heavier classes do fewer total jerks and compensate with presses (p54, Table 4).
- Beginners do identical quantity of cleans and jerks (p54).

### Pulls — only from Class I up (p61–63)
- Low-class: NO pulls; power snatch + power clean develop strength sufficiently (p61).
- Snatch-pull share: I+CMS prep ~7%, comp ~5%; MS prep ~8.5%, comp ~5%.
- Clean-pull share: I+CMS prep ~5%, comp ~6%; MS prep ~10%, comp ~12%.
- Exclude snatch pull altogether is acceptable; replace with power snatch moderate/heavy (world-record examples) (p63).

### Squats (p64–65)
- Front + back squats share (both periods): low avg 27% / I+CMS 23% / MS 20%.
- Other squats share: low ~15% both periods; I+CMS ~6% prep / ~4% comp.
- MS other squats vary by class, prep: light avg 30 / middle 90 / mid-heavy 140 / heavy 260 lifts; comp: light ~none, middle + mid-heavy ~30–50, heavy 80–140.
- Back-squat norms (% of max C&J): MSIC 52/56/60: 137±7%; 67.5: 135.5±6.5%; 75/82.5: 128.7±6%; 90/100/110: 130.3±6%; 110+: 135.5±5.5%. MS: 130.2/129.7/126.8/127.5/129.7 same order. CMS: 129/128.5/126.3/127/128.5. Class I: 127.3/127.1/125.8/126.2/127.1. Low: 126.2/126.1/125.1/125.4/126.1 (p65).

### Presses (p69)
- Low-class both periods: 10% of monthly load; ~70% press-behind-neck snatch grip, remainder bench press clean grip.
- Qualified: highly individual (standing/seated/bench or none); bench example 50–150+ lifts; weight 35–75% C&J, avg 49% prep / 51% comp.

### Isometric / slow / mixed (p74–76, highly-qualified mainly)
- Avg 10% of monthly volume both periods; ~half = "stretches."
- Holding 5–6 s; slow lift 8–15 s; slow lower 6–10 s; lift+lower 15–30 s.
- Weight ~25% (snatch stretches) to 105% (pulls/squats).
- ~50 lifts/week first 3 weeks, almost every workout; heavyweights can increase (prep especially); lightweights keep minimal except snatch/clean stretches (technique).

### Multi-year sequence shares (p83–84, p160–163)
- Beginner: narrow range only; ~1/3 of load = classic snatch + classic C&J (full squat snatch, full squat clean+jerk).
- Low-class: ~1/4 = classic snatch + classic C&J.
- Class I: ~1/5 = classic snatch + classic C&J; adds snatch/clean pulls, standing/lying bend-overs, all presses.
- CMS+MS: full arsenal of special-assistance.
- MSIC: very high preparedness → drop large quantity of assistance; mainly snatch/C&J exercises, clean pulls, squats; reduce others.
- Group 1 (corr. 0.381–0.478 with results): snatch/C&J exercises, front+back squats, clean pulls. Group 2 (corr. 0.229–0.253): snatch pulls, presses, good mornings/hyperextensions ("bend-overs"), other squat variants (p158). Only 90%+ lifts in snatch/C&J exercises correlate moderately (0.518–0.528) (p158).
- Stage volumes/mo (prep month, p159–160): snatch+C&J lifts: novice 300 / I+CMS 330 / MS 340 / MSIC 375 / WR 400. Group-1 assistance: beginner 650 / III–II 738 / I+CMS 910 / MS 1215 / MSIC 1180 / WR 1080. Group-2: novice→MS 150→675, then MSIC 445 / WR 320.

### Superheavyweight 110+ kg specifics (Table 23, p152–154)
- Larger total volume required (muscle-mass maintenance): I+CMS prep 1850 / comp 1280; MS prep 2300 / comp 1600.
- Monthly lifts (share %): I+CMS P/C — snatch 333 (18) / 256 (20); cleans 240 (13) / 179 (14); jerks 176 (9.5) / 128 (10); front+back squat 370 (20) / 269 (21); clean pulls 83 (4.5) / 72 (5.6); fundamental total 1202 (65) / 904 (70.6); snatch pull 93 (5) / 58 (4.5); bend-overs 222 (12) / 96 (7.5); presses 130 (7) / 102 (8); other squats 203 (11) / 120 (9.4).
- MS P/C — snatch 414 (18) / 320 (20); cleans 276 (12) / 192 (12); jerks 244 (10.6) / 192 (12); front+back 414 (18) / 304 (19); clean pulls 207 (9) / 180 (11.2); fundamental 1555 (67.6) / 1188 (74.2); snatch pull 115 (5) / 64 (4); bend-overs 253 (11) / 112 (7); presses 138 (6) / 112 (7); other squats 239 (10.4) / 124 (7.8).
- Peculiarity: fewer jerks (fewer classic jerks than other classes), more presses; fewer snatch pulls; extra volume from presses, bend-overs, other squats, local-effect work, 6-rep fundamental / 10-rep local sets, slow/static/yielding/mixed work; abdominals, barbell jumps, depth jumps.

## 2. Which assistance exercises belong to which lift

- Snatch exercises (p45): classic snatch + power snatch, snatch without squat-under, snatch from hang, snatch from plinths, power snatch from hang, straight-leg snatch, overhead squats (2–3 after first snatch sets, squat or lunge per style), snatch "stretches."
- Clean exercises (p53,58): classic clean (floor/hang/plinths, squat or split — periodically switch style), power clean, clean "stretches."
- Jerk exercises (p53,57–60): classic jerk (usually from stands), push-jerk, push-press, jerk from behind head, press. Push-press done separately or after press with same/slightly heavier weight; ≤5–10 push-presses at 50–80% C&J after press; press weight % = of limit C&J.
- Pulls (p61): snatch pull, clean pull; variants: from lower position (stand on 15 cm platform) or higher (plinths 15 cm+), varied grip width, slow execution.
- Squats (p64,67–68): front, back (squat or lunge), overhead (squat or lunge — 2–3 in first snatch/power-snatch sets), other types (lunge alternating L/R, legs spread, plinth work). Fundamental weight 75–105% C&J; back+front range 45–125% C&J; other squats 35–55% C&J (heavyweight lunge variants 15–25% C&J).
- Presses (p69): standing press (chest / behind-neck; normal/narrow/wide), bench press (flat/incline, varied grips), seated press (chest / behind-neck).
- Combinations (p60–61): front squat + push-jerk/jerk; squat clean + front squat + jerk; all counted rep-by-rep (e.g. 140/2+2).
- Isometric positions (p75): start (bar slightly off platform), after 1st phase, knees-under pre-final-effort, full extension + toes, overhead fixation snatch/C&J, half-squat 90° knee, horizontal bend-over.

## 3. Session composition rules (what goes into one workout)

- 3 parts (p155–156): preparatory (general-developmental slow→fast + special warmup: metal pole / empty bar / minimal weight imitating the lift); fundamental (barbell); conclusion (long/vertical/depth jumps, relaxation, hangs/swings on bars/rings).
- Fundamental order (p156): begin chiefly with SPEED (power snatch, power clean, snatch) → STRENGTH → ENDURANCE / local-effect at end. For pure strength emphasis, strength first. Mix muscle groups (e.g. pulls, bench, squats) to avoid negative habit transfer. Periodically start with different exercise (pulls, squats, presses) to avoid adaptation. Special warmup required when next barbell exercise differs significantly in structure (injury prevention).
- Exercises per workout (p156): 2–3 if small volume; 5–8 if large. Rest 2–5 min between sets; start next set when feeling recovered; breathe as necessary.
- Snatch placement (p48,51–52): basically ONE snatch workout; power snatch almost EVERY workout; other snatch exercises 1–2 workouts. 10–30 lifts/workout in snatch + other snatch; fewer with submax/max. Power snatch frequently BEFORE snatch (then skip minimal/small snatch, go to fundamental weights + 2–3 overhead squats in last two power-snatch sets); before C&J/clean do 6–15 power snatch/clean reps then start C&J/clean 5–15 kg heavier + leg prep (squat-style of the lift in last two power sets). If snatch is mid/end after similar-structure work (cleans, pulls), skip minimal/small, start moderate (e.g. power cleans then snatch 57.5/72.5% 4×4). Submax/max snatch seldom mid-workout, never end. Power snatch first + snatch/C&J second = 10–20 lifts; if heavy snatch/C&J follows use small/moderate power snatch, else small→submax power snatch up to 25–30 lifts in 2 series (start+end or middle+end, heavier in middle/start).
- C&J placement (p55–60): complete classic C&J every 7–10 days; otherwise in PARTS at almost every workout (cleans or jerks). Either 1st or 2nd exercise (e.g. after snatch, power snatch, jerk stretches). One workout can chain: C&J + power clean; clean + jerk + power clean; jerk stretches → clean + push-jerk, etc. 10–30 lifts/workout; fewer with submax/max. Jerk usually from stands; if jerk faulty increase ≤5% set-to-set. Push-press after press (above). Mid-workout jerks = strength; end-workout (4–6 sets, ≤85%, incl. plinth power cleans) = strength-endurance/special endurance. Power clean mid: e.g. 90/4,95/3,102.5/85%/2×3; end: 77.5/65% 6×3–4. Beginners/low: power snatch/clean at start/middle/end; qualified same.
- Pulls (p64): almost every workout; usually snatch pull one workout, clean pull next; both allowed in one; middle or end. 15–30 pulls at 2–4 reps/set; 35–50 at 5–6 reps/set.
- Squats (p68): almost every workout; ~20–30/workout (up to ~60); split into 2 series if large.
- Presses (p69): middle or end when changing muscle groups; 6–30/workout; if jerks/push-jerks done, presses excluded or 6–18; if jerks lacking, increase. No heavy presses when submax/max C&J next workout. Hang from stall-bars/horizontal bar after each submax/max jerk/push-jerk set (prophylactic) (p61).
- Two-a-day (p145, p167 in MS example): desirable when >100 lifts planned; ~200 lifts/day prep / ~180 comp; morning +10 (prep) / +15 (comp) more than evening. Prep: snatch mainly AM; other snatch ~equal AM/PM; C&J 2× AM vs PM; other C&J more PM; most 70%+ AM. Comp: snatch + other snatch ~2× AM; 70%+ equal AM/PM; classic clean/jerk + other cleans ~equal; other jerks + 70%+ C&J mainly AM. Squats: prep ~2× PM incl. 100%+; comp ~equal with slightly more max PM. Other squats: light/middle mainly AM, mid-heavy/heavy PM (both periods). Snatch pulls (+max) AM, clean pulls PM (both periods). Presses AM+PM; good mornings/hyperextensions AM.
- Reps/set norms (Table 1, p46; pulls p63–64; squats p68): snatch/clean/jerk: 4–6 @50–59.9%, 2–3 @60–69.9%, 1–2 @70–79.9%, 1 @80–89.9% (90–100% per text variants). Push-jerk: 4–5 / 3–4 / 1–2 / 1 same zones. Front/back squat: 6–10 / 4–6 / 3–4 / 1–2 @40–49.9→80–89.9%, 1 @90–100%. Pulls prep: 2–6 @80–89/90–99%, 2–5 @100–109%; comp: chiefly 2–4; light 2–3, heavy 4–6, middle either; 100%+ in comp = 1/set as often as possible. Squats: 2–6 @45–85%, 1–6 @95–105%, 1–5 @115%, 1–2 @125% C&J; light 1–3, middle 1–4; other squats 6–10; more reps prep, fewer comp.

## 4. Workouts per week, day splits, rest rules

- Load size (p106): 50 lifts/workout = small (S); 51–100 = moderate (M); >100 = large (L).
- Week-cycle combos excl. Sunday (p106–107): 3×/wk e.g. S-R,L-R,S-R / M-R,L-R,M-R / L-R,S-R,L-R / L-R,M-R,L-R. 4×/wk e.g. S-R,L-R,M,S / L-R,M-R,L,M / L-R,M-R,L,S / L-R,S-R,R,L,S / S-R,M-R,M,S / M-R,L-R,M,S. 5×/wk e.g. M,S,L-R,M,S / M,S,L-R,M,M / S,L,S-R,L,S / L,S,M-R,M,L / S-R,L,M / M,S,M-R,M,S (transcription gaps). 6×/wk e.g. S,M,S,M,S,M / M,S,L,S,M,S / M,L,S,M,S,M / M,M,S,M,M,M / M,S,L,S,M,M / S,L,S,L,S,M. More workouts → larger week volume.
- Sunday: generally excluded from combos; used for competition (p106, p125–127, p141). Last workout before comp often Friday, comp Sunday/Monday (2 days later) (p124–127, p140).
- Example splits (source prescriptions, not templates): low-class max week 450 lifts (p121): Mon 130 L / Tue 40 S / Wed 95 M / Fri 135 L / Sat 50 S ("shock" Mon+Fri). Class III comp 3rd week 216 (p124): Mon 36 / Wed 70 / Fri 25 / Sat 85; 4th week 108: Mon 60 / Wed 30 / Fri 18, Sun comp. Class I 56 kg comp month 1200 (p139–140): wk1 Mon 80/Wed 110/Fri 90/Sat 56; wk2 Mon 85/Tue 50/Wed 105/Fri 90/Sat 66; wk3 Mon 60/Wed 105/Fri 90/Sat 57; wk4 Mon 70/Wed 50/Fri 36, comp Mon (+2 days). MS 90 kg prep (p145): wk1 Mon 90/Tue 60/Wed 100/Fri 110/Sat 77; wk2 100/80/120/130/64; wk3 110/59/90/80/60; wk4 Mon 130/Tue 60/Wed 140/Thu 40/Fri 120/Sat 80.
- After competition: obligatory 3-day rest (e.g. Apr 30–May 2), resume day 4 (p141). First week after comp: gradual increase (e.g. Mon 50/Wed 70/Fri 90/Sat 70), NO submax/max snatch/C&J (p141–142).
- Shock training in comp month preferably same weekday as competition (p110).
- Low-class constraint: ≤2 large (>100) workouts/week (p121).

## 5. Final-week-before-competition structure

- Last-week volume: ~11–14% of month, low intensity (p125); qualified last-week high-intensity ≈10% of month's snatch/C&J high-intensity (≈22 @70–79%, 10 @80–89%, 2 @90%+ for I+CMS) + ~6% of squat high-intensity (≈4 @100%+) (p137). Excess transferred to earlier weeks; clean pulls 100%+ excluded from week 4 (p139).
- Last-lift timing (p109–110): snatch 90–92.5% 5–9 days / 95–97% 6–12 days / 100%+ 7–15 days pre-comp. C&J 90–92.5% 5–13 / 95–97% 7–15 / 100%+ 9–18 days. Squats 100–107.5% 6–10 / 110–117.5% 8–12 / 120%+ 10–16 days. Clean pulls 100–107.5% 8–12 / 110–117.5% 9–15 / 120%+ 11–19 days. Lighter classes later (closer to comp) than heavier (p110).
- Lightweights (I/CMS example, p141): day 1 max volume 70 lifts below-avg intensity; day 3 moderate 50 max intensity; day 5 min 36 moderate; days 6–7 rest; day 8 competition.
- Mid-heavy + heavy (p141): day 1 moderate 50 max intensity; day 3 max 65 below-avg; day 5 min 40 moderate; day 7 min 35 min intensity; day 8 comp. Contrast-directional volume/intensity preferred; individual best variant allowed.
- 56 kg I/CMS comp-month example (p140): week 4 Mon 4× snatch 90–95% ONLY; cleans/jerks 90%+ excluded (done weeks 1+3 instead); max lifts only day 3 or 4 of week.
- Class III example (p124–127): "control" max lifts week 3 — C&J Wed (11 days out), snatch Sat (8 days out); all week-3 90%+ C&J moved to Wed, snatch to Sat; week-4 two 90%+ moved forward to Mon 85 kg; week 4 Mon 60/Wed 30/Fri 18.
- Superheavy: all submax/max snatch/C&J in first 3 weeks of comp month; 100%+ clean pulls also first 3 weeks; good mornings only weeks 1–2; hyperextensions weeks 1–3 (week 4 only 1 day, 16–20 lifts) (p155).
- Heavy (incl. 90 kg): exclude submax/max, especially max, in last week; exclude earlier than lights (p150–151). Best pattern: most 90%+ snatch in week 3, cleans week 2, jerks weeks 1–2, clean-pull max week 1 (36/33/31% weeks 1/2/3) (p150).

## 6. Beginner & low-class specifics (incl. GPP days)

- Beginners — allowed exercises ONLY: snatch, C&J, squats, bench press (p110). Ratio both periods (p110–111): snatch 20% / cleans 13 / jerks 12 / front+back squats 30 / other squats 18 / bench 7%.
- Beginners — schedule (p88–89): Sep–Dec: 3 WL + 1 GPP/wk; ~1150 avg lifts/mo (Sep 1150/Oct 1250/Nov 1200/Dec 1000), ~110/workout; minimal/small/moderate weights, many reps/set; submax/max ONLY in competition. Jan: 2 GPP (incl. skiing) + 1 WL (~500/mo, ~125/wk, minimal/small). Feb–May: 2 cycles (prep+comp each), comp end Mar + end May; 3 WL + 1 GPP/wk; ~1100 prep / 900 comp; add large weights; ~90/prep-workout, ~75/comp-workout. Jun–Jul: 2 GPP + 1 WL minimal/small many reps (~450/mo, ~110/workout). Aug: GPP only, no WL.
- Beginners — technique (p113–117): metal-pole imitation end of each workout; if no squat style, learn split then switch within 6–12 mo if able. First 2–3 mo: power snatch ONLY at start/middle. Initial weights from Table 14 (% of listed max: 16 y/o ≈70%, 17 y/o ≈75% of Class III norms); after first comp use comp snatch/C&J as 100%.
- Low-class — tasks: perfect technique, prepare support-motor apparatus; flexibility (shoulder/knee/ankle), stable squat position, strengthen elbow/shoulder in snatch/C&J positions (p117–118). Fundamental: snatch/C&J exercises, front+back squats, overhead squats, wide-grip press-behind-head (replaces bench as assistance).
- Low-class — no pulls (power lifts suffice) (p118).
- Low-class — classic shares within week/month: ~1/2 snatch lifts classic, ~44% cleans classic, ~68% jerks classic (p121,125); weekly proportion may vary but monthly ratio held.
- Low-class — intensity caps prep: max 90–95% snatch, 90–92.5% C&J (p121); per workout ≤5 @90% / ≤3 @95% C&J; 100% every 10–14 days (vs qualified ~10 submax/max middle-class/workout, lights more, heavies fewer; 95–100% every 2–3 days one exercise, 90% next day or 2–3 days straight across different exercises) (p48,57).
- Low-class comp-month example (75 kg, p118–127): month lifts prep 125/125/94/119/94/44/337/187(sic other squats)/125 press etc.; comp 90/90/68/85/68/31/243/135/90. Zone weights from planned end-month 100% (prep 92/117, comp 94/119). Week % variants Table 13 (e.g. 20/35/27/18 prep, 36/28/24/12 comp).
